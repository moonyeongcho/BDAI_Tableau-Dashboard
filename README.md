## Projects

### 1. E-commerce Marketing Analytics
이커머스 플랫폼 사용자 행동·마케팅 데이터를 기반으로 유입부터 구매까지 흐름을 시각화한 대시보드

- Tableau Public: [바로가기](https://public.tableau.com/app/profile/moonyeong.cho/viz/MarketingE-CommerceDashboard2/1)

### 2. Foodpanda Customer Dashboard
푸드판다 주문 데이터 기반으로 주문 매출 트렌드와 주요 고객 지표를 시각화한 대시보드.  
충성 고객 유지와 이탈 위험 고객 파악에 초점을 맞췄다.
